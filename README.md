# 我的记账本

当前只开发 Android 和 iOS。项目保留 `android/`、`ios/` 和共用的 `lib/` 代码，已移除 Windows、Linux、macOS 电脑版和网页平台入口。

## 在 Windows 电脑上验证 Android

由助手修改代码，备份、Flutter 验证和手机安装由你执行。在 CMD 中依次运行：

```cmd
cd /d D:\Flutter\projects\my_accounting_app
flutter pub get
flutter analyze --no-pub
flutter test --no-pub
```

测试包含账单文件读取、自动分类、退款净额与去重、加密备份与校验、语音文字解析、固定收支日期算法和月份选择交互。测试不启动真实手机数据库；SQLite 迁移与恢复、离线识别、麦克风和通知的实际效果仍需在手机上验证。

没有分析错误、测试全部通过后，使用保留数据的覆盖更新脚本：

```cmd
tools\update_android.cmd
```

手机保持连接，并允许手机弹出的安装确认；电脑显示 `Success` 和 `Update completed` 后打开软件。脚本不会执行卸载或清空数据。

当前项目没有 Windows/Linux 平台目录，Flutter 准备本项目插件时会跳过桌面插件链接步骤。此次没有调整电脑的全局 Flutter 配置或 Windows 开发人员模式。

## 当前功能与验证

最新操作见 [退款、完整备份与离线语音验证](docs/功能更新与验证-20261014.md)。已有功能见 [功能更新与验证](docs/功能更新与验证-20261013.md)。

手机数据保存在本机。现在可以设置密码导出完整备份，恢复时先解密预览再确认替换本机数据，无需云登录。账单 CSV 导出仍只适合账单交换。

中文语音使用软件内置的约 31 MB Zipformer 模型，不依赖手机系统的中文识别服务。模型和运行库会增加安装包大小；录音和识别在手机上完成。

当前个人云同步使用PocketBase：邮箱加密码登录，手机加密后上传按对象保存的版本；另一台设备登录原账号并用恢复码解锁后合并数据，冲突需要用户选择。首次登录还需主动连接加密空间。当前新注册需填写邮件中的6位验证码；原来未验证的账号可在登录页验证已有注册邮箱。发信需服务器配置有效的SMTP账号和客户端授权码。详见 [表格导入、恢复码邮件与数据安全](docs/表格导入与数据安全-20261018.md)。

## iOS（Windows也可准备，无需自备Mac）

已准备Codemagic云端Mac编译配置，分为生成未签名真机IPA（交给自己的工具签名安装）与账号就绪后的签名打包。苹果端最低系统为iOS 15。

当前按无截图识别的基础版更新，包含昵称保存修复和最新邮箱验证码、语音交互。先阅读 [iOS基础版更新与构建](docs/iOS基础版更新与构建-20261019.md)，朋友实测可使用 [iPhone测试清单](docs/iPhone测试清单.md)。

本地配置检查已完成，实际Xcode编译与iPhone真机验证仍待云端账号连接后执行。默认工作流不自动发布或邀请测试者。
