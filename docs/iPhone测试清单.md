# iPhone基础版测试清单

本次为2026-10-19昵称修复版，无截图识别。需先由云端完成Xcode编译，再经适用签名方式安装；本机尚未做原生编译或真机测试。记录iPhone型号与iOS版本，最低iOS15。

1. 在“我的”修改昵称，保存后立刻显示新名称；切换页面、完全关闭并重新打开软件后仍保留。取消修改时不改变原昵称，断网也能修改。
2. 新建余额500元的测试卡，记录关联该卡的50元支出，余额应为450元；再新增20元收入，应为470元。将支出改成60元应为460元，删除支出应为520元，再删除收入回到500元。
3. 记账页分类位于账户选择前，“我的”分为基本管理、数据管理、设置。顶部刘海/灵动岛、底部横条、键盘不遮挡内容和保存按钮。
4. 首页只有手工和语音记账入口，不出现图片按钮；不申请照片或相册权限。
5. 点击语音按钮，授权麦克风并等待“正在听”。说“午饭花了十五块”，结束后核对金额和分类再保存；按住说话、松开结束、上滑取消分别测试。取消、返回或切到后台不应继续录音；断网可识别。
6. 从“文件”导入账单，确认描述作为标题，空描述用分类作标题；取消预览不应创建新分类，重复导入不应重复记账。导出后确认“文件”App中可找到文件。
7. 导出密码加密的完整备份，在测试数据上验证密码和恢复预览。恢复会替换本地业务数据，务必先保留当前备份。
8. 创建固定收支提醒，授权通知并测试到期提醒、点击通知跳转。
9. 用未注册邮箱测试六位验证码注册，用已验证账号和原记账软件密码登录；旧未验证邮箱使用“验证已有注册邮箱”。验证码过期或重发后旧码应不能使用。先确保服务器SMTP测试成功，邮箱密码和客户端授权码不要混用。
10. 登录原云账号后，用原账单恢复码连接加密空间，与Android测试设备同步新增、编辑和删除；有冲突时核对保留版本。登录本身不应删除或自动上传本地账单。
11. 如自愿测试恢复码邮件备份，核对收件人为自己的已验证邮箱，并阅读服务器会接触恢复码的说明。不要将恢复码、密码或授权码放进反馈截图。
12. 检查暗色模式、大字体、横屏与窄屏布局，以及连续打开/关闭昵称、语音和备份页面。

反馈时提供操作步骤、预期与实际结果、界面提示；优先反馈无法保存、重开数据不一致、余额计算错误、恢复失败或闪退。
