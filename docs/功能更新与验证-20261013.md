# 本轮功能更新与验证

本轮按你的工作方式只修改代码。Flutter 获取依赖、分析、测试、手机更新和界面验证都由你执行；备份也由你执行。

## 1. 命令验证

在 Windows 的命令提示符 CMD 中，依次运行：

```cmd
cd /d D:\Flutter\projects\my_accounting_app
flutter pub get
flutter analyze --no-pub
flutter test --no-pub
```

先执行 `flutter pub get`，之后才能用 `--no-pub` 检查。保留现有 lock 文件，由此命令更新依赖；无需升级 Flutter。2026-10-14 的离线语音、退款净额和完整备份更新见同目录的新验证文档。

旧的 Flutter 默认计数器测试已替换为月份选择交互测试。全量测试不会再用该测试启动真实手机数据库；数据库迁移、账单保存、语音权限和通知效果仍由手机实机验证。

分析没有 error、测试全部通过后，继续使用之前保留数据的覆盖更新脚本：

```cmd
tools\update_android.cmd
```

手机保持连接，出现 USB 安装确认时允许。电脑显示 `Success` 和 `Update completed` 后，再打开软件。此脚本不执行卸载或清除数据。

如果任一步出现 error 或测试失败，请把完整输出反馈；本轮还未在真实手机或 Flutter 测试环境执行验证。

## 2. 导入自动分类

- 支付宝、微信默认自动分类。原交易分类明确时优先映射；否则参考商品名称、商户和备注。
- 餐饮、交通、购物、住房、娱乐等会对应你的现有分类。牛奶和日用品优先购物，餐厅和外卖对应餐饮。
- 无法识别、证据冲突、对应分类不存在：支出归其他支出，收入归其他收入。缺失这两个分类时会补建，保留原有分类。
- 导入选项可以关闭自动分类，改为统一手动分类。正常账单和待核对候选都处理；导入预览显示分类名称。
- 本软件导出的有效分类优先保留，新导出文件保留分类名称；退款来源列追加在其后，旧列位置及旧文件仍兼容。

请用新账单检查几种分类，再重复导入同一个文件，查看是否正确跳过已经导入的账单。过去已导入的记录不会批量改写，需要时仍可逐笔编辑。

## 3. 隐藏金额、选择年月和按钮

- 首页收入：眼睛按钮仍在收入标题旁；隐藏后金额和人民币符号都不显示，区域留白。再次点击即可恢复。
- 资产：总资产和总负债各有独立的眼睛。资产隐藏时，资产账户金额、分组总额一起隐藏；负债隐藏时，负债余额、贷款总额和剩余额一起隐藏。
- 隐藏状态保存到本机设置，关闭再打开软件后应保留。图表继续显示比例，不显示金额。主动打开编辑账户或调整余额时仍可查看并编辑金额。
- 月份格保持单行，10、11、12 月不再换行；左右切年，点击年份直接输入或从年份列表选择，保留“回到本月”。
- 首页右下角只保留两个圆形图标：笔图标用于手动记账，麦克风用于语音记账；滚动时保持图标，不再展开文字。列表底部保留空间，最后一笔仍能完整查看。

请在手机上检查：收入隐藏与恢复、资产/负债分别隐藏、小屏或大字体下月份布局、快速上下滑动和最后一笔账单。

## 4. 语音记账

入口：首页右下角独立麦克风，或“我的 → 语音记账”。点击开始说话，首次使用允许麦克风权限。

例如说：“今天我买了两包牛奶，花了七元。”应生成今天、支出 7 元、名称牛奶、分类购物的草稿。点击“核对账单”，选择账户和账本、检查内容后保存。

第一版在本机用规则提取一笔账单，可识别常见数字、中文金额、今天/昨天/前天以及明确的年月日。多个金额、金额格式不明确或日期不明确时会提示你填写或核对。

2026-10-14 起，语音转文字使用软件内置的中文离线模型，不依赖系统的中文语音识别服务。录音在内存中送给本机模型；不写录音文件，不上传音频。仍支持输入一句话生成草稿。

请检查：示例句、昨天收到工资、多个金额、取消/退出录音页面、拒绝权限后文字录入。最终保存成功后首页应只有一笔新记录。

## 5. 固定收支

入口：“我的 → 固定收支”。房租、房贷、车贷、手机月租、视频/其他订阅、工资和自定义模板可设置名称、收支方向、每月金额、账本、账户、分类、每月日期和开始日期。

- 到期后出现待确认项，首页也会提示；确认时可核对本期实际金额和日期，确认成功才加入账单。
- 每月 29、30、31 号遇到短月时按该月最后一天处理。
- 同一期重复确认不会重复新增。删除已经生成的账单后，此期仍保留完成状态，不会自动重新生成。
- 可跳过本期、暂停或删除计划。暂停之前已到期的项目仍保留待核对；暂停期间不补生成期次，重新开启从当日起恢复。
- 计划修改用于之后的期次；已经到期的项目保留原计划快照，可在确认时单独修改。
- 如果实际付款已经手动或从微信/支付宝导入，选择“已记过这笔，关联已有账单”，核对名称、金额和日期后关联。本期完成，已有账单不再新增。
- 如果先确认固定收支，之后再导入同一笔平台付款，两个来源目前不会自动合并，仍需核对；不能仅凭相同金额判断是同一笔交易。
- 固定收支记账沿用现有行为，不自动调整资产账户余额。

先创建一个“今天到期、金额 7 元”的测试计划，检查首页提示；确认后首页应新增一筆，返回固定收支后这期应消失。再检查跳过、暂停、编辑、关联已有账单，并删除测试计划和测试账单。

## 6. 手机到期通知

固定收支页面打开“每月到期提醒”，允许系统通知权限，然后点击“发送测试提醒”，查看通知栏并点击通知，确认可以打开固定收支页面。发送测试提醒也会开启该功能。

启用后安排到期日上午 9 点左右的本地提醒，同一天多个计划合并提醒。Android 使用普通非精确提醒，不要求精确闹钟权限；系统省电策略可能延迟或限制显示，首页待确认项仍然保留。

通知不展示金额。首次安排未来六个月，最多六十个日期；每次打开/回到软件或修改计划都会重新安排续期。长期超过半年不打开软件，需要再次打开才会续排。待确认的积压项保留在软件中，也会安排一次次日上午的提醒。

Android、iOS 权限与通知配置都已加入，目前交给你验证 Android；iOS 后面需要 Mac/Xcode 环境单独验证。
