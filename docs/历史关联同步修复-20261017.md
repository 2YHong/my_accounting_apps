# 历史关联同步修复（2026-10-17）

此前提示“部分本地数据缺少可同步的关联”，本次从已连接测试手机的本地诊断副本定位到：导入核对、固定收支历史记录仍引用此前已删除的账单，而这些删除发生在同步标识建立之前。账号和加密空间已有绑定，问题出在本机整理待同步记录阶段。

这属于同步程序对正常历史记录处理不完整。保留历史记录本身有用，不需要清空账单、重建密钥或重装数据库。修复通过覆盖安装生效，服务器和集合结构无需再修改。

## 处理方式

- 对历史引用中确实已经不存在、也没有其他用户同步标识的目标，建立“已删除对象”的同步标识。
- 仅补齐内部同步信息，不创建账单、金额、分类或账户的业务行。
- 在同一事务里把新增删除标识加入本次上传准备，另一台设备据此转换历史编号。
- 合并时允许合法的历史记录引用已删除对象，现行账单的必需关联继续检查。
- 为删除标识预留本地自增编号，防止未来新账单错误继承旧对象身份。
- 遇到另一个本地用户拥有的对象继续停止同步，不自动改变归属。
- 嵌套历史列表顺序处理，避免重复引用同一个已删除对象时竞争创建标识。

数据库仍为版本 9，加密协议仍为版本 1，原恢复码与根密钥继续使用。
