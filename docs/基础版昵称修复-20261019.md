# 基础版昵称保存修复（2026-10-19）

本次基于无截图识别的基础版。截图测试版暂不继续开发。

昵称失败原因：原用户对象序列化包含SQLite用户表没有的 created_at 列；写入失败之前又修改了内存对象，可能造成页面后来显示新名字、实际没有保存的错觉。此外旧弹窗人为等待300毫秒再保存。

本次改为只更新昵称列，成功后重新读取显示；保存过程中显示正在保存，防止重复提交，失败保留输入允许重试。移除固定等待，控制器由弹窗自身管理生命周期。账号ID、邮箱、密码字段和云端关联不随昵称修改而重写；不需要数据库升级或服务器修改。

## 安装与核对

Android基础版沿用原应用ID和签名，提升版本号，使用APK覆盖安装即可。无需卸载旧版。适用于ARM64安卓手机。
更新前保留完整备份和恢复码。
安装后到“我的”修改昵称，保存成功后切换页面、关闭并重新打开软件，再核对昵称。断网修改也应保存成功。
本次没有在用户手机安装或读取手机账单。

iOS包含相同修复和当前共享代码，仍是云编译源码包。尚未配置云构建，因此未生成实际IPA或完成iPhone测试。操作见 iOS基础版更新与构建-20261019.md。
