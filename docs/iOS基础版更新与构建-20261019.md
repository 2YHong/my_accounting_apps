# iOS 基础版更新（2026-10-19，昵称修复版）

本次以无截图识别的 Android 基础版为准。保留当前账单、本地数据库、账户余额联动、导入导出、备份恢复、离线语音、邮箱验证码及端到端加密同步。

## 本次更新

- 修复昵称写入时带入用户表不存在的 created_at 字段的问题；昵称更新只写 username，保留账号标识、邮箱和云端关联。
- 修改昵称先等待数据库写入成功，再关闭弹窗并重新读取显示；失败保留输入、允许重试，不提前改变页面里的用户对象。去掉原先固定等待300毫秒的做法。
- 同步最新语音入口：点击开始、再次确认结束；按住说话、松开结束、上滑取消；识别文字仍需核对后保存账单。
- 同步六位邮件验证码注册、验证已有注册邮箱、恢复码邮件备份及现有CSV标题导入。
- iOS 不加入截图识别依赖、不增加相册或照片权限，不显示截图记账入口。云构建、模拟器和签名构建都明确禁用该入口。
- 原应用标识 xyz.698239.myaccountingapp、最低 iOS 15、图标、麦克风用途、通知和钥匙串配置保留。

## 交付物和当前限制

这个 ZIP 是云构建用源码，不能直接安装在 iPhone，也不能改后缀充当 IPA。
目前电脑是 Windows，用户尚未配置云构建，因此没有执行 Xcode 编译、没有生成真实 IPA、没有做 iPhone 真机测试。
本次没有连接任何云构建账号、上传源码、创建签名密钥或发布应用。

## 无需自备 Mac 的下一步

1. 将源码 ZIP 解压，把内容上传到自己的私有 Git 仓库根目录。根目录直接包含 codemagic.yaml、pubspec.yaml、lib、ios、tools，不要只上传压缩包或多套一层目录。
2. 在 Codemagic 连接该仓库并添加 Flutter 应用。
3. 选择工作流“iOS 基础版 - 生成未签名 IPA（自行签名）”，手动构建。不需要在这条流程填写苹果账号或证书。
4. 等待检查和原生编译成功，再在 Artifacts 下载 my-accounting-app-unsigned.ipa。它仍需要测试者采用适用的签名方式安装。
5. SIMULATOR-only-not-for-iphone.zip 仅用于模拟器，不能装在手机上。

构建仍固定 Flutter 3.38.7 和 Xcode 26.2；如平台已经不提供所选镜像，应保留平台提示再调整，不先升级项目依赖。
实际 iOS 体积只能在云编译后测量，不能用 Android APK 的体积代替。
如选择正式签名或 TestFlight，沿用此前说明中的签名工作流和账号配置；不会自动上传商店。
旧说明见 iOS云构建与测试-20261018.md，其中旧功能说明和测试数量不代表本次结果。

## 服务器关系

昵称修复与本次 iOS 更新不需要重装服务器。
数字验证码依赖已有的 email-code 接口和有效 SMTP 配置。服务器曾返回535时，仍需正确填写发信邮箱账号和客户端授权码并实际测试收信。
验证码为六位短期数字；账单恢复码用于解密，两者用途不同。
选择服务器发送恢复码时，服务器和邮件服务会接触恢复码，需在软件明确同意。
